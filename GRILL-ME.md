# Ҙурбаш (Zurbash) — итоги grill-me

Рабочее название проекта было Bashlingo, продукт переименован в «Ҙурбаш».

## Продукт и демо

Ҙурбаш помогает школьникам учить башкирский. Первый сценарий — русскоязычный ученик. Подача в духе Duolingo: короткие уроки, дорожка прогресса, объёмные кнопки, опыт, серии занятий и соревнования. Маскот — куница. На момент обсуждения до демонстрации было три дня, разработчик один.

Для демо выбрали пару башкирский → русский и три темы по два коротких урока: знакомство, семья и школа. Форматы — выбор перевода, сопоставление пар и сборка фразы. Источник упражнений — [разговорники Bashkorttele](https://huggingface.co/datasets/bashkorttele/trilingual-parallel-phrasebooks-bgpu). Используем пары из датасета без генерации нейросетью и сохраняем ссылку на источник. Предварительная проверка каждой пары не обязательна.

## Уровни и задания

При первом входе ученик выбирает уровень:

1. Начинаю с нуля.
2. Знаю отдельные слова.
3. Понимаю простые фразы.
4. Понимаю, но не могу говорить.
5. Уровень родного языка.

«Задание дня» подбирается из датасета по уровню ученика. Ориентир для демо — пять упражнений. Продвинутые участники могут помогать с проверкой переводов. Самооценка уровня не даёт права официально утверждать переводы.

## Школы и классы

Учитель создаёт школу и класс. Ученик присоединяется по ссылке или коду и может начать учиться самостоятельно до вступления. Учитель добавляет свои карточки, собирает их в наборы и назначает своему классу. «От учителя» и «Задание дня» — отдельные разделы. Учитель видит выполнение назначенных заданий. В проекте предусмотрены рейтинги класса и школы.

## Проверка переводов

После ответа показываем подпись **«В переводе ошибка?»**. При нажатии ученик указывает причину и, если знает, предлагает свой перевод. Можно написать «не понимаю перевод» без своего варианта.

Если за один вариант голосуют не менее 80% участников при минимум пяти разных голосующих, он может использоваться в упражнениях со статусом **«Выбран сообществом»**. При отсутствии согласия материал остаётся спорным и доступным для выгрузки экспертам. Исходный перевод, предложения, причины, голоса и история изменений сохраняются.

Выгрузка включает исходный фрагмент и источник, прежний перевод, предложенные варианты, количество и долю голосов и статус, в том числе **«Выбран сообществом»**. Экспертное подтверждение даёт УФИЦ РАН, официальные изменения вносит заказчик. У преподавателей и администраторов приложения права официального утверждения нет.

## Сайт и Telegram

Сайт и Telegram Mini App используют один адаптивный интерфейс. Бот самостоятельно отвечает на команды и позволяет пройти задание в переписке. Аккаунт, класс и прогресс общие для всех трёх точек входа. Повторное прохождение уже учтённого задания не начисляет опыт повторно.

| Команда | Действие |
|---|---|
| `/start` | Регистрация, выбор уровня или возврат в приложение |
| `/profile` | Уровень, опыт, серия дней, школа и класс |
| `/daily` | Задание дня в переписке |
| `/homework` | Наборы от учителя |
| `/rating` | Рейтинг класса и школы |
| `/join` | Вступление по коду |
| `/help` | Справка |
| `/cancel` | Выход из текущего задания |

Бот также показывает оценку перевода после ответа и кнопку «Открыть Ҙурбаш». PostgreSQL и REST API обязательны по ТЗ. Состояние задания в боте хранится в БД. Для реализации предложены Next.js и отдельный процесс бота.

## Открытые вопросы

- Выбрать компоновку главной из [четырёх вариантов](design-explorations/bashlingo-directions.html). В обсуждении рекомендован вариант A с дорожкой уроков.
- Определить, как сопоставлять равнозначные формулировки и пересматривать решение сообщества при новых голосах.
- Сверить объём демо с [ТЗ](Техническое%20задание.pdf), включая аудиоматериалы, отчёты преподавателя, документацию API и развёртывание.
