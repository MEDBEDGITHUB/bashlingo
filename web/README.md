# Ҙурбаш (Zurbash) — веб-приложение и Telegram Mini App

Учебная платформа для башкирского языка в духе Duolingo: дорожка уроков, упражнения трёх типов (выбор перевода, пары, сборка фразы), опыт, серии дней, классы и рейтинги. Каждый ответ и каждое замечание «В переводе ошибка?» сохраняются, так что из них собирается база переводов (ТЗ, п. 5).

Один и тот же интерфейс работает как сайт и как Telegram Mini App.

Стек: Next.js 15 (App Router), PostgreSQL 13+ и драйвер `pg`. ORM нет, схема лежит в [`db/schema.sql`](db/schema.sql).

## Запуск локально

Нужны Node.js 20+ и PostgreSQL 13+.

```bash
npm install
cp .env.example .env        # указать пароли и секреты
npm run db:setup            # создаёт роль, базу и таблицы, загружает курс и демо-данные
npm run dev                 # http://localhost:3000
```

`db:setup` можно запускать повторно: схема и курс обновятся, а данные пользователей останутся.

Продакшен: `npm run build && npm start`. `ADMIN_DATABASE_URL` нужна только для `db:setup`.

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | подключение приложения к PostgreSQL |
| `SESSION_SECRET` | подпись cookie сессии; длинная случайная строка |
| `ADMIN_KEY` | ключ входа в админ-панель `/admin` |
| `TELEGRAM_BOT_TOKEN` | токен бота; без него вход через Telegram отключён |

## Роли

| Роль | Как появляется | Что может |
|---|---|---|
| Ученик | выбирает «Я ученик» при первом входе | учится сам; по коду класса вступает в класс |
| Учитель | выбирает «Я учитель» и вводит **код школы** либо создаёт школу | создаёт классы, свои наборы карточек, задания; видит отчёт по классу |
| Администратор | входит на `/admin` по `ADMIN_KEY` | видит статистику, школы, спорные переводы; создаёт школы |

### Коды

- **Код школы** (например, `SIBAY1`) привязывает учителя к школе. Его выдаёт администратор, когда создаёт школу, или получает первый учитель, если создаёт школу сам. Учитель видит код в своём кабинете и передаёт коллегам.
- **Код класса** (например, `7B2026`) учитель получает, когда создаёт класс. Ученик вводит его при первом входе или во вкладке «Класс». Вместо кода можно отправить ссылку `/join/<код>`.

Коды состоят из 6 символов без похожих букв и цифр (нет `0/O`, `1/I/L`), регистр при вводе не важен.

### Кабинет учителя (`/teacher`)

- список классов: число учеников, сколько занимались за неделю, опыт за неделю;
- страница класса: код и ссылка-приглашение, задания с прогрессом, таблица учеников (опыт, серия, пройденные уроки, точность, отметки по каждому заданию) и выгрузка отчёта в CSV;
- задание — это урок курса или свой набор карточек со сроком сдачи;
- набор карточек: минимум 3 пары «фраза — перевод», есть кнопки башкирских букв. Карточки учителя не попадают в выгрузку базы переводов.

### Демо-данные

`db:setup` создаёт школу № 1 (Сибай, код `SIBAY1`), класс 7 «Б» (код `7B2026`) с учителем, пятью учениками и заданием. Войти под демо-учителем:

```bash
npm run login-link -- "Гульшат Ринатовна"
```

Команда печатает ссылку для входа, которая действует 15 минут.

## Задание дня и согласование переводов

- **Задание дня** подбирается по уровню ученика (5 фраз). В нём есть упражнение **«Правильно ли переведена фраза?»**: ученику показывают фрагмент и перевод, примерно в половине случаев подставлен перевод другой фразы (ТЗ 4.3). Ученик подтверждает перевод или исправляет его, выбрав верный вариант или написав свой.
- Подмену определяет **сервер**: перевод считается подменённым, если он не совпадает с исходным переводом фрагмента. Клиенту доверять верность нельзя. Найденная подмена даёт +2 XP и бейдж «Корректор».
- Каждая проверка пишется в таблицу `checks`. Если ученик считает исходный перевод неверным и предлагает свой, это попадает в `reports` как голос в согласовании.
- После любого ответа в уроке доступно «В переводе ошибка?» с причиной и своим вариантом.
- Итог по фрагментам собирается в выгрузке `/api/translations` и в админ-панели: `confirmed`, `expert_review` или `community` (≥80% при ≥5 голосующих).

## Достижения и рейтинги

Бейджи (9 штук): первый урок, урок без ошибок, 3 и 7 дней подряд, 5 заданий дня, 100 и 500 XP, «Корректор», раздел пройден. Они видны в профиле и выдаются сразу после прохождения.

Рейтинг класса считается за день, неделю, месяц или год по четырём показателям: опыт, словарный запас (разные фразы, отвеченные верно), доля верных ответов (от 5 ответов) и число исправлений. Тот же рейтинг отдаёт `GET /api/classes/:id/leaderboard?period=&metric=xp|words|accuracy|fixes`.

## Аккаунты и вход

Паролей нет. На сайте аккаунт привязан к браузеру подписанной cookie `zb_uid`. Перенести его на другое устройство можно ссылкой из профиля («Войти на другом устройстве», действует 15 минут). В Telegram аккаунт привязан к Telegram-профилю и восстанавливается сам.

## Telegram: бот и Mini App

Бот `@zurbash_bot` и Mini App работают на одной базе: аккаунт, класс и опыт общие для сайта и Telegram.

### Бот (`npm run bot`)

Отдельный процесс, работает через long polling, так что публичный адрес ему не нужен. Состояние диалога хранится в таблице `bot_state`, поэтому перезапуск не сбрасывает задание.

| Команда | Что делает |
|---|---|
| `/start` | регистрация ученика: имя, уровень (диплинк `t.me/zurbash_bot?start=КОД` сразу вступает в класс) |
| `/daily` | задание дня в переписке: выбор перевода и проверка перевода (иногда он подменён) |
| `/homework` | задания от учителя |
| `/profile` | уровень, опыт, серия, бейджи |
| `/rating` | рейтинг класса за неделю |
| `/join КОД` | вступить в класс |
| `/cancel` | выйти из задания |
| `/help` | справка |

Учителя регистрируются на сайте или в Mini App, в боте только ученики. Кнопка «Открыть Ҙурбаш» и кнопка меню Mini App появляются, когда `PUBLIC_URL` начинается с `https://`.

Если на машине с ботом интернет идёт через прокси (переменные `HTTPS_PROXY`/`HTTP_PROXY`), запускайте бота с `NODE_USE_ENV_PROXY=1`: сам Node.js 24+ не использует прокси из окружения, и без этой переменной бот не достучится до `api.telegram.org`.

### Mini App

1. Токен бота записан в `TELEGRAM_BOT_TOKEN`.
2. Разверните приложение по HTTPS: Telegram открывает Mini App только по HTTPS-адресу.
3. Укажите `PUBLIC_URL=https://ваш-адрес` и перезапустите бота: он сам поставит кнопку меню.

Как это работает: внутри Telegram страница подключает `telegram-web-app.js`, отправляет подписанные данные `initData` на `POST /api/auth/telegram`, сервер проверяет подпись токеном бота (HMAC-SHA256, данные не старше суток) и выдаёт сессию. Новый пользователь проходит ту же регистрацию, а имя подставляется из Telegram. Если человек уже учился на сайте в этом же браузере, его аккаунт привязывается к Telegram. Обычным посетителям сайта скрипт Telegram не загружается.

## Развёртывание на сервере (Docker)

Нужен сервер с Docker и открытыми портами 80 и 443. Настраивать HTTPS не нужно: в составе есть Caddy, он сам получает сертификат Let's Encrypt.

```bash
cp .env.docker.example .env.docker   # заполнить пароли, токен бота и DOMAIN
docker compose --env-file .env.docker up -d --build
```

Поднимутся четыре контейнера: `db` (PostgreSQL), `web` (сайт, API и админка), `bot` и `caddy` (HTTPS на портах 80 и 443). Схема и курс применяются при каждом старте. Бот сам ставит кнопку меню Mini App на `https://DOMAIN`.

**Домен.** Нужна A-запись домена на IP сервера. Если домена нет, возьмите бесплатный адрес с IP через sslip.io: для сервера `203.0.113.7` это `203-0-113-7.sslip.io`, его записать в `DOMAIN`. Сертификат Caddy выпустит примерно за минуту.

**Проверка:** откройте `https://DOMAIN`, затем бота в Telegram: рядом со строкой ввода появится кнопка «Ҙурбаш». Логи: `docker compose logs -f web bot caddy`. Cookie в продакшене выдаются с `SameSite=None; Secure`, поэтому сайт должен открываться по HTTPS (с Caddy так и есть).

Демо-класс создаётся при первом запуске: код школы `SIBAY1`, код класса `7B2026`. Перед публичным показом смените `ADMIN_KEY`.

## Данные курса

[`db/course.json`](db/course.json) — 3 раздела по 2 урока, всего 45 фраз из разговорника [Bashkorttele (БГПУ)](https://huggingface.co/datasets/bashkorttele/trilingual-parallel-phrasebooks-bgpu), конфиг `ba-ru-kk`. Фразы взяты из датасета без изменений, у каждой сохранён номер строки источника.

## Схема данных

| Таблица | Что хранит |
|---|---|
| `fragments` | `id`, `text_ba`, `lang_pair`, `translation_auto` (перевод из источника), `source` (jsonb: документ, строка, датасет), `origin` (`dataset` или `teacher`) |
| `units`, `lessons`, `lesson_fragments` | структура курса |
| `users` | имя, роль (`student`/`teacher`), уровень 1–5, класс (ученик) или школа (учитель), серия дней, `telegram_id` |
| `schools` | название, город, код школы |
| `classes` | школа, учитель, название, код вступления |
| `card_sets`, `card_set_items` | наборы карточек учителя |
| `assignments` | задание классу: урок курса или набор, срок сдачи |
| `completions` | учтённые прохождения: урок, `set:<id>` или `daily:YYYY-MM-DD`. Повторное прохождение опыт не даёт |
| `xp_events` | начисления опыта, по ним считаются рейтинги за день, неделю, месяц и год |
| `answers` | каждый ответ: фрагмент, тип упражнения, верно или нет |
| `reports` | «В переводе ошибка?»: причина и предложенный вариант |

## REST API

Тело запросов — JSON с заголовком `Content-Type: application/json`. Пользователь определяется по cookie сессии.

### Открытые данные

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/fragments?lang_pair=ba-ru&limit=100&offset=0` | Фрагменты корпуса с координатами источника |
| `GET` | `/api/translations?lang_pair=ba-ru&status=&format=json\|csv` | Выгрузка базы переводов по схеме ТЗ п. 5 |

### Ученик

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/users` | Регистрация ученика `{name, level: 1..5, joinCode?}` или учителя `{role: "teacher", name, schoolCode}` / `{role: "teacher", name, newSchool: {name, city}}`. Поле `initData` привязывает аккаунт к Telegram |
| `GET` | `/api/users` | Текущий пользователь: роль, опыт, серия, класс, школа |
| `POST` | `/api/auth/telegram` | Вход из Mini App `{initData}` |
| `POST` | `/api/auth/logout` | Выйти из аккаунта в этом браузере |
| `POST` / `GET` | `/api/auth/link` | Выдать ссылку для входа на другом устройстве / войти по ней |
| `POST` | `/api/progress` | Итог урока `{lesson: slug \| "daily" \| "set-<id>", results: [{fragmentId, type, correct}]}` → `{awarded, mistakes, repeat, streak}` |
| `POST` | `/api/reports` | Замечание к переводу `{fragmentId, reason, proposed?}` |
| `POST` | `/api/classes/join` | Вступить в класс `{code}` |
| `GET` | `/api/classes/:id/leaderboard?period=day\|week\|month\|year` | Рейтинг класса; доступен ученикам класса, его учителю и администратору |

### Учитель

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/teacher/classes` | Создать класс `{name}` → `{id, name, join_code}` |
| `POST` | `/api/teacher/sets` | Создать набор `{title, cards: [{ba, ru}]}` |
| `POST` | `/api/teacher/assignments` | Задать классу `{classId, lessonSlug \| setId, dueDate: "YYYY-MM-DD", title?}` |
| `DELETE` | `/api/teacher/assignments` | Снять задание `{id}` |
| `GET` | `/api/teacher/classes/:id/report?format=json\|csv` | Отчёт по классу для учителя и LMS |

### Администратор

| Метод | Путь | Описание |
|---|---|---|
| `POST` / `DELETE` | `/api/admin/login` | Войти `{key}` / выйти |
| `POST` | `/api/admin/schools` | Создать школу `{name, city}` → код школы |

### Выгрузка переводов

Поля: `fragment_id`, `text_ba`, `lang_pair`, `translation`, `translation_source`, `source`, `confirmed` (сколько пользователей ответили верно), `reports`, `status`.

Статусы:
- `confirmed` — замечаний нет;
- `expert_review` — есть замечания, согласия нет: спорный случай для экспертов УФИЦ РАН;
- `community` — один предложенный вариант набрал не меньше 80% голосов при минимум пяти разных голосующих. Тогда в `translation` подставляется он, а исходный перевод остаётся в `translation_source`.

Список спорных случаев с вариантами и причинами виден в админ-панели.

## Что ещё не сделано

- Упражнения «пары» и «сборка фразы» есть только на сайте; в боте доступны выбор перевода и проверка перевода.
- Учитель не может редактировать набор после создания, исключить ученика из класса или удалить класс.
- Администратор не может редактировать и удалять школы и пользователей из панели.
- Озвучка: кнопка 🔊 появляется, только если в браузере есть башкирский голос.
- Отдельного экрана голосования за чужие варианты нет: голосом считается каждое замечание с предложенным вариантом (в уроке и в проверке перевода).
