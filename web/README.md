# Bashlingo — веб-приложение

Учебная платформа для башкирского языка в духе Duolingo: дорожка уроков, упражнения трёх типов (выбор перевода, пары, сборка фразы), опыт, серии дней, классы и рейтинги. Каждый ответ и каждое замечание «В переводе ошибка?» сохраняются, так что из них собирается база переводов (ТЗ, п. 5).

Стек: Next.js 15 (App Router), PostgreSQL 13+ и драйвер `pg`. ORM нет, схема лежит в [`db/schema.sql`](db/schema.sql).

## Запуск локально

Нужны Node.js 20+ и PostgreSQL 13+.

```bash
npm install
cp .env.example .env        # указать пароли
npm run db:setup            # создаёт роль, базу и таблицы, загружает курс и демо-класс
npm run dev                 # http://localhost:3000
```

`db:setup` можно запускать повторно: курс обновится, а данные пользователей останутся. Он создаёт демо-класс «7 «Б»» школы № 1 (Сибай) с кодом **`7B2026`**, пятью одноклассниками и заданием от учителя.

Продакшен: `npm run build && npm start`. Переменные окружения те же. `ADMIN_DATABASE_URL` нужна только для `db:setup`.

## Данные курса

[`db/course.json`](db/course.json) — 3 раздела по 2 урока, всего 45 фраз из разговорника [Bashkorttele (БГПУ)](https://huggingface.co/datasets/bashkorttele/trilingual-parallel-phrasebooks-bgpu), конфиг `ba-ru-kk`. Фразы взяты из датасета без изменений, у каждой сохранён номер строки источника. Сборка курса из датасета описана в `../data/`.

## Схема данных

| Таблица | Что хранит |
|---|---|
| `fragments` | `id`, `text_ba`, `lang_pair`, `translation_auto` (перевод из источника), `source` (jsonb: документ, строка, датасет) |
| `units`, `lessons`, `lesson_fragments` | структура курса |
| `users` | имя, уровень 1–5, языковая пара, класс, серия дней, `telegram_id` для бота |
| `schools`, `classes`, `assignments` | школы, классы с кодом вступления, задания учителя |
| `completions` | учтённые прохождения: урок или `daily:YYYY-MM-DD`. Повторное прохождение опыт не даёт |
| `xp_events` | начисления опыта, по ним считаются рейтинги за день, неделю, месяц и год |
| `answers` | каждый ответ: фрагмент, тип упражнения, верно или нет |
| `reports` | «В переводе ошибка?»: причина и предложенный вариант |

## REST API

Пользователь определяется по cookie `bl_uid`, которую выставляет `POST /api/users`.

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/users` | Регистрация `{name, level: 1..5, joinCode?}` |
| `GET` | `/api/users` | Текущий пользователь: опыт, серия, класс |
| `GET` | `/api/fragments?lang_pair=ba-ru&limit=100&offset=0` | Фрагменты с координатами источника |
| `POST` | `/api/progress` | Итог урока `{lesson: slug \| "daily", results: [{fragmentId, type, correct}]}`. Возвращает `{awarded, mistakes, repeat, streak}` |
| `POST` | `/api/reports` | Замечание к переводу `{fragmentId, reason, proposed?}` |
| `POST` | `/api/classes/join` | Вступить в класс `{code}` |
| `GET` | `/api/classes/:id/leaderboard?period=day\|week\|month\|year` | Рейтинг класса |
| `GET` | `/api/translations?lang_pair=ba-ru&status=&format=json\|csv` | Выгрузка базы переводов по схеме ТЗ п. 5 |

### Выгрузка переводов

Поля: `fragment_id`, `text_ba`, `lang_pair`, `translation`, `translation_source`, `source`, `confirmed` (сколько пользователей ответили верно), `reports`, `status`.

Статусы:
- `confirmed` — замечаний нет;
- `expert_review` — есть замечания, согласия нет: спорный случай для экспертов УФИЦ РАН;
- `community` — один предложенный вариант набрал не меньше 80% голосов при минимум пяти разных голосующих. Тогда в `translation` подставляется он, а исходный перевод остаётся в `translation_source`.

## Что ещё не сделано

- Telegram-бот (`/start`, `/daily`, `/cancel` и т. д.). Схема уже готова: `users.telegram_id`, общий прогресс.
- Кабинет учителя: создание класса, своих карточек и наборов. Сейчас класс и задание создаются только сидом.
- Озвучка: кнопка 🔊 появляется, только если в браузере есть башкирский голос.
- Голосование за предложенные варианты: пока голосом считается само замечание с вариантом.
