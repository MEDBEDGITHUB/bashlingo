# Данные дизайн-прототипа

Дата: 2026-11-13. Все четыре варианта используют одинаковые демонстрационные данные.

| Элемент | Поле / источник | Класс | Количество |
|---|---|---|---|
| Башкирская фраза и русский перевод в диалоге | dataset-sample.json, rows[].row.text_ba/text_ru, выбран id=bgpu-alt-00001 | Real — текст источника, не экспертная проверка | 1 пара используется; 5 строк загружено |
| 3 дня серии, 120 XP, 10/20 XP | user.streak, user.xp, daily.xp | Aspirational — иллюстративные значения | 0 настоящих профилей |
| Текущий урок и прогресс дорожки | user.lessonProgress | Aspirational | 0 записей прогресса |
| Знакомство, Семья, Школа | Согласованный бриф | Aspirational — структура курса согласована, контент ещё не подготовлен | 3 темы, 0 готовых уроков |
| Задание дня | dailyAssignment | Aspirational | 0 сгенерированных наборов; 5 упражнений предложено в брифе |
| От учителя: 6 карточек | class.assignment | Aspirational — демонстрационное число | 0 реальных назначений |
| Куница | Встроенный SVG | Real — созданная иллюстрация | 1 предварительный персонаж |
| Оценка перевода | translationFeedback | Aspirational — локальное переключение состояний | 0 сохранённых голосов |

Источник пары: https://huggingface.co/datasets/bashkorttele/trilingual-parallel-phrasebooks-bgpu, конфигурация ba-ru-alt, train. Варианты перевода и ошибки выравнивания могут присутствовать. В макете строка «Другой вариант» — явный UI-заполнитель, не готовый учебный дистрактор.
Датасет указывает CC BY 4.0; полная атрибуция из NOTICE должна быть добавлена при подготовке учебного корпуса. В макет импортирована только небольшая выборка для проверки дизайна.
Рабочие БД, API, Telegram и экспертная выгрузка ещё не реализованы. Редактирование и отправка замечания в диалоге не сохраняют данные.
