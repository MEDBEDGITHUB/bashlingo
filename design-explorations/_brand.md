# Bashlingo — оформление сравнения

Дата: 2026-11-13.

Сканирование: готовых дизайн-систем, токенов и интерфейса нет; в корне только ТЗ.
Рамка сравнения: нейтральные светлые цвета из шаблона explore-design; системный шрифт Segoe UI, Georgia для заголовка документа. Без внешних шрифтов.
Продукт: согласованный игровой характер Duolingo, собственная куница, название Bashlingo. Предлагаемые общие токены всех вариантов: зелёный #237a46, лаймовый #b7ec70, тёплый белый #fffef9, тёмный текст #233b31, рыжий персонаж. Формы округлые, кнопки с нижней тенью, контрастные подписи.
Рисунок куницы — предварительная векторная иллюстрация, не утверждённый финальный маскот.
Дизайн-системы проекта пока нет. Компоновки показывают один и тот же демонстрационный профиль, не настоящую статистику пользователя.
